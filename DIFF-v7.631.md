# AmazonDark v7.631 — performance path repair

The v7.630 performance capture confirms Product Detail responseEnd 2.54s, domInteractive 15.64s and native theme hooks totaling tens of milliseconds, so the large main-thread layout hooks alone cannot explain the loading delay. The following changes target WebKit work without changing UI paint on Search/PDP:

1. **Checkout-only stylesheet suppression on Search/PDP:** The existing byte-identical `ADCheckoutFloorJS7369`, `ADCheckoutTWBJS7369`, and `ADCheckoutBYGHydrateJS7378` payloads are now guarded by the shared `WKUserScript` assembler so they exit immediately for exact `/s`, `/dp`, `/gp/product/`, and `/gp/aw/d/` paths. Checkout floors/TWB and hydration are unchanged on checkout/cart and every other route. The checkout-only floor stylesheet is ~84 KB of source, containing 107 `:has()` selectors, and has no `#dp` or Search selectors. Removing it from Search/PDP reduces avoidable CSS selector matching and invalidation. No app-specific CSS is deleted.
2. **No full-page forced layout for ad feedback:** `ADNewMenus7622.js` skips the whole-page `body.innerText` classifier on Search/PDP automatic DOMContentLoaded/pageshow. Click-triggered feedback classification still uses its original **visible text** test, so hidden Home templates cannot accidentally enable feedback styling. Generated `.js.inc` rebuilt byte-for-byte from JS.
3. **Working WebKit performance observations:** while explicitly armed, `ADPerformance7596.inc` now pulls current WebKit metrics via the already-working eval-return bridge every five seconds, including *during loading*. It caps work to eight visible WKWebViews/tick, stops immediately after session completion, and records periodic success/missing counts. No additional production timers, observers, scanners, hooks or scroll mutation.
4. Current version/probes/commands updated to v7.631; all prior theming retained.

**Limits:** This removes proven redundant stylesheet work but is *not yet an on-device demonstration that the entire 15s delay is fixed*. Capture v7.631 and compare Search/PDP `domInteractive`, touch-to-scroll and frame gaps against the actual v7.630 capture. Other expensive CSS remains for future probe-guided isolation.
