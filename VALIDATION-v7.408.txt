Root cause of prior regression coverage
---------------------------------------
v7.389 intentionally matched one exact teal checkout shield.
v7.402 intentionally matched neutral payment shields, but required live checkout/payment state.
Those source-contract tests passed because those narrow contracts were still present. They did not prove
that a different foreground React sheet could never trigger the same inactive visual-effect mechanism.
The location sheet therefore bypassed both older owners even though the resulting switcher card looked
nearly identical to the payment regression.

v7.408 switcher invariant
-------------------------
Neutral switcher protection is now based on the common lifecycle/geometry invariant instead of route names:
- AmazonDark enabled
- app state is not Active
- exact Amazon AppCXWindow
- UIVisualEffectView >=94% of window width and >=78% of window height
- effect or immediate effect/content child has neutral gray-to-white tint with meaningful alpha
- keyboard visual effects excluded
- no checkout modal, payment sheet, bottom-sheet, SNPViewController or AMIWebViewController prerequisite

The claimed transient view is hidden / alpha-zero / layer-opacity-zero only while inactive. Its authored
UIVisualEffect object is not destroyed or replaced. If the same view survives foregrounding, its original
hidden/alpha/layer-opacity values are restored. Re-show / re-alpha writes are rejected only while inactive.
The old exact teal and payment-specific owners remain only as compatibility fallbacks.

New regression strategy
-----------------------
- test_v7408_permission_location_switcher_hardening.py asserts the generalized owner has no route/payment prerequisite.
- tests/fixtures/v7408-location-switcher-shield.json records the exact failing probe witness.
- test_v7408_location_switcher_probe_fixture.py proves that witness satisfies the generalized invariant and would fail if
  the owner becomes route/payment-specific again.

Performance / architecture
--------------------------
No new MutationObserver, interval, RAF loop, Web scroll listener, polling loop, recurring hierarchy scan,
fake app-switcher snapshot, SpringBoard scene painter, or WKUserScript family was introduced.
All new native work is event-driven from existing UIView / React / UIVisualEffectView lifecycle hooks.
