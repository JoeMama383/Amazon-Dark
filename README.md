# AmazonDark v6.0.201 experimental — direct OLED WebKit floors

Experimental performance architecture built from the v6.0.199 production source. Dark Reader remains packaged only for easy rollback but is no longer attached, evaluated, enabled, or repaired at runtime. Amazon WebKit pages instead receive one small document-start OLED stylesheet plus the existing TWB and symbol owners. The stylesheet directly owns the page canvas and common Amazon structural surfaces, preserves media wrappers for TWB, and uses CSS inheritance/token selectors for normal foreground text. No new recurring scan, scroll listener, interval, RAF loop, or MutationObserver is added.
