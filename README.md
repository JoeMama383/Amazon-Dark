# AmazonDark v7.395 — UI coverage audit fix

v7.395 is built directly on v7.394 and retains the completed Payment Method, Privacy/Returns/Consumer Tax, help-feedback, checkout Subscribe & Save, app-switcher, gift-options, delivery-address, recurrence-selector and prior AmazonDark theming work.

v7.395 retains the four v7.394 UI corrections and adds three latent-state fixes found during a complete probe-to-selector re-audit:

- **Help search typed-query suggestions:** the hidden `#help_srch_sggst` list that can replace the default suggested-topics panel is now OLED black with light text and gray separators.
- **Add-address location feedback/error states:** pre-mounted location feedback and location-detection error surfaces are darkened so `Use my location` cannot expose a latent white panel.
- **Pickup success/error alerts:** pre-mounted Bolt alert cards become OLED while Amazon's red/green accent borders remain authored.
- **All v7.394 visible-state work remains:** Add an address controls, pickup map/sort/cards/action, Delivery/Pickup toggle, Subscribe & Save help suggestions, dark keyboard/accessory, plus all v7.393 payment/help-article and earlier checkout fixes.

No MutationObserver, polling loop, interval, RAF loop, Web scroll listener, new recurring hierarchy scanner, new WKUserScript, generic image filter, or app-switcher cover is added. The new native keyboard work is event-driven on responder/mount/layout events already generated by UIKit/WebKit.

See `AUDIT-v7.395.md` and `COMMANDS.md`.
