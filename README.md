# AmazonDark v6.0.202 experimental — direct static theme parity

Built from the v6.0.201 DarkReader-free performance experiment. Dark Reader remains packaged only for rollback and is still not attached, parsed, evaluated, enabled, or repaired at runtime.

This pass treats the prior screenshot/version history as a visual regression atlas. The accumulated `ADFixesLiteral().css` ownership sheet is now injected directly at document start, without the Dark Reader engine, restoring the established checkbox/action glyphs, Sponsored treatment, Share glyph, carousel dot, swatch/status/expander fixes, mosaic borders, and other screenshot-driven declarative owners. A second direct stylesheet supplies OLED-black page floors plus the established charcoal card hierarchy, light primary/secondary text, gray borders, Home/Search/Cart/PDP/Share structural ownership, and exact removal of known white structural gradients such as `wd-backdrop-gradient`.

Performance rule: CSS-only for the new theming layer. v6.0.202 adds no MutationObserver, DOM TreeWalker, scroll callback, setInterval, requestAnimationFrame, recurring timer, computed-style census, or page-wide repair pass. Existing TWB and symbol/event owners are retained. Product/media artwork remains excluded from structural background painting so TWB can tame bright pixels without recreating black boxes behind logos/transparent creative art.
